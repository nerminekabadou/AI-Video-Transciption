Hi Soumya,

I've completed the coding assignment and built a working proof of concept web application for video upload and AI-powered question answering. Here's what I've implemented:

**What I Built:**
- A full-stack web application with a Next.js frontend and FastAPI backend
- Video upload functionality supporting files up to 2GB
- Automatic audio extraction from videos using FFmpeg
- Speech-to-text transcription using AssemblyAI
- AI-powered question answering about video content
- Real-time progress tracking with status updates
- Modern, responsive UI built with Tailwind CSS

**Technical Implementation:**
- **Frontend**: Next.js 16 with React 19
- **Backend**: FastAPI (Python) running on localhost:8000
- **Transcription**: AssemblyAI API for audio-to-text conversion
- **AI Model**: Currently using Groq API with Llama 3.3 70B model (can be easily switched to Mistral Small 3.1 as requested)
- **Video Processing**: FFmpeg for audio extraction

**Key Features:**
- Drag-and-drop video upload interface
- Background processing with job status tracking
- Real-time progress updates during transcription
- Interactive Q&A interface for asking questions about video content
- Error handling and user feedback
